# 自定义壁纸与扩展主题

## 上传一张图，搭配现成的界面配色

1. 在 DSH 打开 **设置 → 通用设置 → DSH 一键换肤**，展开皮肤预览。
2. 在 **自定义壁纸** 里上传一张 JPG、PNG 或 WebP，文件须在 20 MB 以内。自己的照片、插画和已生成的 AI 图片都可以用。
3. 从 **界面配色** 里选一套颜色，点 **应用我的壁纸**。例如偏暖的照片可以搭配「晴窗猫咪」，青绿色的插画可以搭配「海风微语」。

上传的图片会缩放至长边最多 1920 像素，保存在当前 DSH 桌面配置中。之后可以在预览里选 **我的壁纸** 切回来，也可以在相同位置换图或换配色。保持插件启用并使用同一个桌面配置，重启后会继续使用上次选中的皮肤。

## 新增一套自己的主题

准备一份仓库副本和 Node.js。从 GitHub 下载 ZIP 后解压，或用 Git 克隆。以下以 ID 为 `rainy-studio` 的「雨天工作室」为例。

1. 在 [`themes.json`](../themes.json) 里复制「海风微语」等一整条主题，粘贴到数组末尾。把 `id` 改成 `rainy-studio`，`name` 改成「雨天工作室」，再填写 `description`。ID 用小写英文和连字符，并与其他主题区分开。
2. 把壁纸导出为 `assets/rainy-studio.png`，把缩略图导出为 `assets/rainy-studio.jpg`。两个文件名都要与 ID 一致。壁纸建议用 1280 × 720 或更大的横图，预览缩略图建议用 320 × 180。
3. 保留复制条目里的 `colors` 字段，先改 `bg-primary`（聊天区底色）、`sidebar-bg`（侧栏）、`card-bg`（卡片与代码块）、`input-bg`（输入框）以及 `accent`（链接与高亮）。颜色沿用原条目的格式。想调整裁剪时，`focusX` 是通常窗口的水平位置，`compactFocusX` 是窄窗的水平位置，`focusY` 是垂直位置。取值范围是 0 到 1，例如水平位置 0.5 为居中，越接近 1 越靠右。
4. 在项目根目录运行下面两条命令。构建会把配置编进 DSH 实际加载的 `lib/client.js`。

   ```sh
   npm run build
   npm run check
   ```

5. 在 DSH 的 **插件 → 添加插件** 中输入这个本地项目的绝对路径，安装并启用。如果 DSH 提示已安装同名插件，先在插件页卸载原版本，再添加本地目录。回到通用设置选择「雨天工作室」，分别用宽窗和窄窗查看取景，再用带代码块的对话检查文字和输入框。

想直接替换某套内置主题时，可以沿用它的 ID，更新同名 PNG、JPG 和配色后重新构建。源码修改只应用于你安装的那份副本。

## 让 DSH 帮你改主题

在 DSH 中打开仓库副本，把准备好的壁纸和缩略图放到工作区，再按自己的图片路径和风格改写这段话。构建完成后，按上面的步骤在插件页启用本地版本。

> 我要做一套叫「雨天工作室」的浅色皮肤。壁纸和缩略图已经放在工作区。请参考「海风微语」的结构，在 themes.json 新增 rainy-studio，把图片放到 assets 下并用同一个 ID 命名。用偏冷的灰蓝做聊天区底色，侧栏和输入框用更浅的颜色，窄窗取景偏右。沿用其他 13 套主题，构建并检查后告诉我怎么在设置里选到这套。
